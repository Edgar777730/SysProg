### Модуль управления на Python («Мозг» агента)

Скрипт `brain.py` отвечает за взаимодействие с нативным ядром при помощи `ctypes`, периодический опрос его функций и логику определения инцидентов (нарушений). Базовая реализация добавляется на занятии №3. Подробный план развития директории и появления модулей зафиксирован в `agent/README.md`.

| Файл | Назначение |
| :--- | :--- |
| `brain.py` | Инициализирует библиотеку ядра через `ctypes`, получает системные метрики и формирует вывод в формате JSON. |
