## Управляющий модуль агента (Python)

Скрипт `brain.py` выступает связующим звеном с нативной библиотекой на C: он подключает ядро через `ctypes`, периодически запрашивает системные метрики и анализирует состояние процессов на предмет аномалий. Начальная версия модуля реализуется в рамках 3-го практического занятия. Полная карта файлов проекта и порядок их добавления описаны в `agent/README.md`.

| Файл | Описание |
| :--- | :--- |
| `brain.py` | Подключает скомпилированное ядро через `ctypes`, собирает данные о хосте и процессах и сериализует отчёт в JSON. |
