## Системное ядро (C)

Низкоуровневая логика компилируется в динамическую библиотеку в зависимости от ОС: `sentry_core.dll` (Windows), `libsentry_core.dylib` (macOS) или `libsentry_core.so` (Linux). Первый рабочий функционал появляется на 2-й паре.

**Команда сборки для Windows:**
```cmd
cl /nologo /W4 /LD core_info.c core_procs.c core_spawn.c core_cpu.c /Fe:sentry_core.dll
```

### Состав файлов проекта

| Описание и функционал | Имя файла |
|---|---|
| Консольная проверка вывода перечня процессов на C | `list_procs.c` |
| Получение системной информации через `core_get_info` | `core_info.c` |
| Пример атомарного увеличения счетчика без гонки данных | `race.c` |
| Запуск дочерних задач (`core_spawn`) и их ожидание (`core_wait`) | `core_spawn.c` |
| Тестовая утилита для подсчета количества потоков на C | `count_threads.c` |
| Заголовочный файл с объявлениями функций и структурами | `core.h` |
| Сбор списка активных процессов через `core_list_procs` | `core_procs.c` |
| Проверка работы запуска и ожидания процессов на C | `run_child.c` |
| Подсчет процессорного времени функцией `core_proc_cpu` | `core_cpu.c` |
| Утилита для тестирования замеров времени процессора на C | `cpu_top.c` |
