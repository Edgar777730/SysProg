## Системное ядро на языке C

Низкоуровневая часть проекта компилируется в разделяемую библиотеку под целевую операционную систему:
* **Windows:** `sentry_core.dll`
* **macOS:** `libsentry_core.dylib`
* **Linux:** `libsentry_core.so`

*(Базовый функционал ядра закладывается начиная со второго практического занятия).*

### Компиляция под Windows (MSVC)
Для сборки динамической библиотеки из командной строки разработчика используется команда:
```cmd
cl /nologo /W4 /LD core_info.c core_procs.c core_spawn.c core_cpu.c /Fe:sentry_core.dll
```

### Структура исходных кодов

| Назначение и описание | Тип компонента | Имя файла |
|---|---|---|
| Объявление сигнатур функций и описание базовых структур | Заголовок | `core.h` |
| Получение общих данных об операционной системе (`core_get_info`) | Модуль ядра | `core_info.c` |
| Сбор и возврат перечня запущенных процессов (`core_list_procs`) | Модуль ядра | `core_procs.c` |
| Создание дочерних процессов (`core_spawn`) и контроль их завершения (`core_wait`) | Модуль ядра | `core_spawn.c` |
| Расчет и получение времени работы процессора (`core_proc_cpu`) | Модуль ядра | `core_cpu.c` |
| Консольная утилита для отладки вывода списка процессов | Тест | `list_procs.c` |
| Тестирование запуска дочерних задач и ожидания их ответа | Тест | `run_child.c` |
| Проверка корректности подсчета процессорного времени | Тест | `cpu_top.c` |
| Тестовый стенд для подсчета активных потоков | Тест | `count_threads.c` |
| Пример потокобезопасного инкремента с использованием атомарных операций | Демо | `race.c` |
